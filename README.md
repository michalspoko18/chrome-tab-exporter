# Chrome Tab Exporter

A Google Chrome extension that allows you to view, export, and import all your open tabs across devices.

## Features

- View all open tabs with their titles and URLs
- Search through your open tabs
- Select specific tabs to export
- Export selected tabs as JSON files
- Import previously exported tabs on the same or different device
- Quickly navigate to a tab by clicking on it in the list

## Installation

### From Source

1. Clone this repository or download the zip file
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the folder containing the extension files
5. The extension should now be installed and accessible from your toolbar

## Usage

1. Click the Chrome Tab Exporter icon in your toolbar to open the popup
2. View and search through your open tabs
3. Select tabs you want to export using the checkboxes
4. Click "Export Selected Tabs" to download a JSON file containing your tabs
5. On another device, click "Import Tabs" and select a previously exported JSON file to open those tabs

## Privacy

This extension works entirely locally on your device. No tab data is sent to any remote servers. Your exported tab data is saved only as a local file that you control.
